# Афиша Ташкента — прототип

Собирает анонсы мероприятий из публичных Telegram-каналов и с сайта afisha.uz,
складывает их в одну базу, убирает дубли и показывает на странице по датам.

## Сайт
**https://strivarde.github.io/afisha/**. Афиша обновляется сама каждые 3 часа на серверах GitHub,
компьютер для этого включать не нужно.
- Запустить обновление вручную: GitHub → репозиторий → **Actions** → «Обновить афишу» → **Run workflow**.
- Ключ нейросети хранится в GitHub: Settings → Secrets and variables → Actions → `LLM_API_KEY`.
- База событий (`data/events.db`) после каждого обновления сохраняется в репозиторий.

## Локальный запуск (необязательно)
Дважды кликнуть **`Обновить афишу.bat`**. Скрипт соберёт свежие посты, разберёт их
и откроет страницу `output/index.html` в браузере. Это удобно для экспериментов. На сайт
локальный запуск не влияет: сайт собирается на GitHub.

## Источники
- **Сайты:** afisha.uz, iTicket, ShowGo, Olbilet, Ticketon (с серверов GitHub отдаёт 0 событий),
  квизы «Смузи» и Albert Party. С билетных сайтов берутся цена и ссылка «Купить билет».
- **Telegram:** список в `sources.json` плюс каналы, найденные автопоиском. Среди них квизы:
  «Мозгобойня», «Квиз, плиз!», «Шейкер», RazumBoy, UZQUIZ.
- **Категория «Игры»:** квизы, мафия, настольные и интеллектуальные игры, турниры. Квесты в «комнатах»
  и прочие постоянные развлечения не попадают в афишу.

## Автопоиск новых источников
Система сама ищет новые Telegram-каналы с анонсами в двух местах:
- в постах уже подключённых каналов: пересылки, ссылки `t.me/...`, упоминания `@канал`;
- на страницах площадок afisha.uz: клубы, театры, галереи, концертные залы, коворкинги и т.д.

Каждый найденный канал проверяет нейросеть. С оценкой 7 из 10 и выше канал добавляется в афишу
автоматически. Каждое обычное обновление проверяет до 10 новых кандидатов, поэтому список постепенно растёт.

- **`Найти новые источники.bat`** — большой поиск (5–15 минут). В конце откроется отчёт `output/sources.html`:
  что добавлено, что отклонено и почему, плюс Instagram площадок на будущее.
- `discover.py --all-venues` — ещё и рестораны с кафе (около 1 600 мест, долго).

## Как добавить или убрать источник
Открыть `sources.json` в Блокноте и дописать имя канала (то, что идёт после `t.me/`)
в список `telegram`. Работают только **публичные** каналы.

## Точность разбора
Посты из Telegram разбирает бесплатная нейросеть Google Gemini. Ключ хранится в файле `.env`,
проверить его можно файлом **`Проверить ключ.bat`**. Нейросеть получает только посты,
похожие на анонсы, пачками по 8. Если бесплатный лимит закончится или сервер Google
не ответит, разбор продолжится по правилам: это менее точно, но афиша всё равно обновится.

Данные с afisha.uz приходят уже в готовом виде, нейросеть для них не нужна.

## Устройство (для разработчика)
| Файл | Что делает |
|---|---|
| `tgscrape.py` | читает t.me/s/<канал> без аккаунта |
| `sites.py` | сборщики сайтов (afisha.uz через открытый JSON API) |
| `extract.py` | текст поста → события (правила или LLM через OpenAI-совместимый API) |
| `db.py` | SQLite `data/events.db`, склейка дублей |
| `render.py` | HTML-страница |
| `run.py` | весь цикл; `--reparse` переразбирает сохранённые посты |
| `tests_extract.py` | проверка правил разбора |
